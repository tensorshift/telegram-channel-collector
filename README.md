# Telegram Channel Collector

Полностью автономное Chrome/Edge-расширение для сбора и анализа постов каналов в Telegram Web.

Версия 2.0 выполняет весь анализ прямо в браузере. Python, Docker, локальный сервер, API-ключи и интернет-сервисы для анализа не нужны. Данные канала никуда не отправляются.

Интерфейс расширения и лендинг используют локально поставляемый шрифт Pixelify Sans. Внешние шрифты, CDN и аналитические счётчики не подключаются.

## Установка готовой сборки

1. Распакуйте `telegram-channel-collector-standalone.zip` в отдельную папку.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку.
5. Закрепите значок расширения на панели браузера.

Это единственный ручной шаг, который нельзя убрать у расширения без публикации в Chrome Web Store или Microsoft Edge Add-ons: браузеры не разрешают обычную установку неподписанных расширений двойным кликом.

## Использование

1. Откройте [Telegram Web](https://web.telegram.org) и перейдите в канал.
2. Откройте расширение и нажмите **Начать сбор**.
3. Прокручивайте историю канала. Сбор продолжает работать, даже если закрыть popup расширения.
4. Нажмите **Стоп**, когда постов достаточно.
5. Нажмите **Анализировать** для локального отчёта или **Завершить и скачать** для JSON.
6. В результатах анализа можно скачать автономный HTML-отчёт.

Для более устойчивой статистики желательно собрать не менее 50–60 постов.

## Что анализируется

- просмотры: среднее, медиана, разброс и выбросы;
- вовлечённость, репосты и охват относительно подписчиков;
- разнообразие и энтропия реакций;
- регулярность и часы публикаций;
- доля медиа, пересланных постов, опросов и ссылок;
- эвристический fraud score с расшифровкой сработавших сигналов.

Fraud score — ориентир для первичной проверки, а не доказательство накрутки.

## Файлы standalone-расширения

```text
manifest.json    — конфигурация Manifest V3
popup.html       — интерфейс
popup.js         — логика интерфейса и экспорта
analyzer.js      — локальный аналитический движок
content.js       — сбор данных из Telegram Web
background.js    — скачивание JSON и HTML-отчётов
assets/fonts/     — Pixelify Sans и текст лицензии OFL
icon*.png        — иконки
INSTALL.txt      — короткая инструкция для получателя
```

Папки `api/`, `bot/`, `ANALYZER/`, а также Docker-файлы оставлены в репозитории как архив старой серверной реализации. Standalone-сборка их не содержит и не использует.

## Сборка архива

Из PowerShell в папке проекта:

```powershell
.\build-standalone.ps1
```

Готовый архив появится в `release/telegram-channel-collector-standalone.zip`.

Сценарий одновременно обновляет архив для скачивания на лендинге: `docs/downloads/telegram-channel-collector-standalone.zip`.

## Лендинг и GitHub Pages

Готовый статический лендинг находится в `docs/`. Для него не нужны Node.js, сборщик или серверная часть. Workflow `.github/workflows/pages.yml` публикует эту папку в GitHub Pages после push в ветку `main`.

## Безопасность и приватность

- standalone-расширение не содержит токенов и не запрашивает API-ключи;
- анализ выполняется локально, а результаты сохраняются через браузер;
- минимальные разрешения расширения: `activeTab`, `downloads` и `scripting` (для автоматического восстановления сборщика после обновления расширения);
- локальные `.env`, выгрузки аналитики, ключи и распакованные сборки исключены через `.gitignore`;
- правила сообщения об уязвимостях описаны в `SECURITY.md`.

Если токен когда-либо попадал в опубликованную историю Git, одного удаления файла недостаточно — токен нужно отозвать и выпустить заново.
