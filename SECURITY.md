# Security Policy

## Сообщить об уязвимости

Не публикуйте токены, ключи, выгрузки каналов и другие чувствительные данные в открытом issue.

Если в репозитории доступны GitHub Private Vulnerability Reporting или Security Advisories, используйте их. Иначе свяжитесь с владельцем репозитория приватным способом и приложите минимальный пример, достаточный для воспроизведения проблемы.

## Секреты

Standalone-расширение не требует секретов. Переменная `BOT_TOKEN` относится только к архивной серверной реализации и должна храниться исключительно в локальном `.env`, который исключён из Git.

Если секрет уже был опубликован, удаление файла из текущей версии не делает его безопасным: секрет необходимо немедленно отозвать и заменить.
