[ FAQ ]

Коротко о важном.

Нужен ли Python или Docker?

Нет. Аналитический движок написан на JavaScript и работает внутри расширения.

Данные отправляются наружу?

Нет. Расширение не использует сервер для сбора или анализа данных.

Это определяет накрутку со 100% точностью?

Нет. Fraud score — эвристический сигнал для первичной проверки, а не доказательство.

Почему установка не в один клик?

Браузеры запрещают обычную установку неподписанных расширений. Для установки в один клик нужна публикация в официальном магазине.
