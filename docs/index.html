[ INSTALLATION ]

Three simple steps.
No terminal required.

Chrome requires Developer mode for extensions installed outside the Chrome Web Store. You only need to set it up once.

Unzip it first. Chrome's Load unpacked button cannot open a ZIP file — it only accepts the extracted folder containing manifest.json.
  1. 01

    Download, then unzip

    Download the extension ZIP and extract it before continuing. Do not select the ZIP in Chrome.

  2. 02

    Open Chrome Extensions

    chrome://extensions

    If Chrome blocks the direct link, paste the copied address into the address bar. Using Edge? Open edge://extensions.

  3. 03

    Enable and load the folder

    Turn on Developer mode, click Load unpacked, and select the extracted folder containing manifest.json — not the ZIP file.
